# Status Report

Щотижневий звіт для Sponsor (формат і канал: [Communication Plan](confluence/parts/10-communication-plan.pdf)). Один звіт на тиждень, найновіший зверху. Фактичні поля заповнюються з Jira й [бюджету](budget.md); порожні поля означають «ще не заповнено», а не «все добре».

## Шаблон

```
## Тиждень [дата понеділка] – [дата неділі], Sprint [N]

Загальний стан: 🟢 / 🟡 / 🔴  (одним реченням чому)

Зроблено:
- [задача Jira: результат]

Заплановано на наступний тиждень:
- [задача Jira]

Показники:
- Прогрес спринту: [N] з [M] SP
- Бюджет: витрачено [X] год із 432, прогноз до завершення [Y] год
- Строки: MVP 13.12.2026 — [в плані / ризик: що саме]

Ризики й проблеми (зі змінами за тиждень):
- [R-xx]: [стан, що робимо]

Рішення, потрібні від Sponsor:
- [питання, варіанти, дата рішення]
```

Правила: стан 🟡 або 🔴 завжди супроводжується варіантами та датою рішення; «рішення від Sponsor» не залишати порожнім без позначки «немає».
