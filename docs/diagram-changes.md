# Зміни в діаграмах (Draw.io)

Список розбіжностей між діаграмами з `docs/diagrams/` і кодом проєкту. Формат: **що змінити → як саме**.

## 1. Діаграма класів (`OOP3`)

- **User: поля** → додати `# passwordHash : String` під `# email`.
- **User: методи** → замінити `login() : bool` на `+ login(password: String) : bool`, `logout() : void` залишити.
- **Client: поля** → додати `- notification: string` після `- address`.
- **Manager.notifyClient** → замінити на `+ notifyClient(client: Client, message: String): void`.
- **Order.status** → замінити `-status: string` на `-status: OrderStatus`.
- **Order.updateStatus** → замінити на `+updateStatus(newStatus: OrderStatus): void`.
- **Order: поля** → додати `-isConfirmedByClient: bool` і `-review: string`.
- **Car.status** → замінити `- status: string` на `- status: CarStatus`.
- **Нові перелічення** → додати два блоки зі стереотипом `«enumeration»`:
  - `OrderStatus`: New, DocumentsRequested, InProgress, BidWon, BidLost, Invoiced, PaymentPending, Paid, Shipping, Completed, Cancelled, DocumentsProvided;
  - `CarStatus`: Available, Auction, Reserved, Paid, InTransit, ReadyForPickup, Delivered, SoldToOther.
  
  Пунктирною стрілкою залежності з'єднати Order → OrderStatus і Car → CarStatus.
- **Delivery: поля** → додати `-photoReportNote: string`, `-hasCargoInsurance: bool`, `-cargoInsuranceCost: double`, `-mandateGeneratedAt: dateTime`.
- **CarCatalog: методи** → додати `+ search(filter: CarSearchFilter, onlyAvailable: bool) : Car[]` і `+ getByIds(ids: int[]) : Car[]`.
- **Зв'язок Order — Car («стосується»)** → кратність біля Order змінити з `1` на `0..*`, біля Car залишити `0..1`. Додати примітку: «активна заявка на авто — лише одна».
- **Зв'язок Order — Delivery («включає»)** → перенести зафарбований ромб від Delivery до Order. Кратності не змінювати: Order `1`, Delivery `0..1`.

## 2. Діаграма діяльності (`statediagram`)

- **Повернення після «Вибрати інше авто або змінити бюджет»** → стрілку, що зараз іде до ромба-злиття перед «Взяти участь в аукціоні», перевести до ромба-злиття перед «Обробити заявку клієнта». Біля стрілки дописати: «заявка знову [нова]».
- **Fork/join логіста** → прибрати обидві жирні смуги. «Згенерувати доручення», «Замовити додаткове страхування вантажу» і «Додати фотозвіт стану авто» зробити необов'язковими:
  - після «Призначити перевізника по США» поставити ромб-рішення «Потрібні додаткові дії?»;
  - гілка [Так] веде до цих трьох дій;
  - гілка [Ні] і вихід із дій сходяться в ромбі-злитті перед «Оформити митні документи».
- **Скасування заявки** → додати від «Створити заявку на підбір авто» (стан «Заявка [нова]» / «в роботі») ще одну стрілку до «Скасувати заявку». Підпис: [клієнт скасовує до виграшу ставки].
- **Очікування підтвердження оплати** → між «Оплатити інвойс» і ромбом «Оплата надійшла?» додати об'єкт `b: Інвойс [оплата очікує підтвердження]`.
- **«Змінити статус на оплачено та сповістити логіста»** → перейменувати на «Змінити статус на оплачено (заявка з'являється в списку логіста)».

## 3. Діаграма станів (`OOP4`)

- **Видалення авто з каталогу** → додати перехід від «Доступно» до кінцевого стану з підписом [авто видалено з каталогу].

## 4. Діаграма прецедентів (`OOPfirst`)

- **Автентифікація** → додати прецеденти «Зареєструватися» (лише Клієнт), «Увійти» та «Вийти» (усі три актори).
- **Клієнт** → додати прецеденти, з'єднані з актором Клієнт:
  - «Змінити заявку (авто / бюджет)» і «Скасувати заявку» — як «extend» до «Створити заявку на підбір авто»;
  - «Надати документи» — як «extend» до «Запитати додаткові документи» або окремим прецедентом клієнта.
- **Менеджер: каталог авто** → додати прецедент «Вести каталог авто (додати / редагувати / видалити)», з'єднаний з Менеджером.
- **Менеджер: заявки** → додати «Видалити заявку» (з'єднати з Менеджером) і «Відхилити оплату (оплата не надійшла)» (як «extend» до «Зафіксувати оплату»).
- **Логіст** → додати «Згенерувати доручення» як «extend» до «Призначити перевізника» (поруч зі страхуванням вантажу і фотозвітом).
- **«Експортувати звіт у PDF / Excel»** → перейменувати на «Експортувати звіт (CSV для Excel / друк у PDF)».
